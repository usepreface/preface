# @usepreface/dashboard

The Preface dashboard: a Vite single-page app on TanStack Router (file-based routes). For now it
has the onboarding flow and the empty organization home from Figma pages 56–57, in light and dark.
It is UI only: nothing talks to the server yet, forms validate in the browser and submitting moves
to the next screen.

```sh
pnpm --filter @usepreface/dashboard dev       # http://localhost:3000
pnpm --filter @usepreface/dashboard build
pnpm --filter @usepreface/dashboard preview   # serves the build on port 3000
```

## Routes

- `/setup`: step 1, set up the instance and the owner account.
- `/setup/organization`: step 2, create the first organization and its URL. `admin`, `api`,
  `settings` and `preface` show the slug-taken state.
- `/`: the empty organization home inside the app shell (`_app` layout: top bar, sidebar, panel).
  Only Home is a route; the other sidebar items are placeholders.

## Structure

- `src/main.tsx`: router, theme and tooltip providers.
- `src/routes/__root.tsx`: head tags and the not-found page.
- `src/routes/setup/`: the two setup steps. `-components/` holds the split layout, the aside points
  and the organization preview.
- `src/routes/_app.tsx`: the app shell. Below 1024 px the sidebar moves into a sheet.
- `src/routes/_app/index.tsx`: the home page. `-components/` holds the sidebar, top bar, setup
  checklist, sources card and invite card.
- `src/components/theme-switch.tsx`: light, dark or system. In the setup footer and the account menu.
- `src/lib/placeholder.ts`: the sample instance, owner and organization shown until the API is wired.
- `src/routeTree.gen.ts`: generated by the router plugin on `dev` and `build`; don't edit it.

The `-` prefix keeps component folders out of the generated route tree. The theme is applied before
first paint by the script in `index.html` and stored under `preface-theme`, like the other apps.
